# spi — ناقل SPI

> **🕒 مخطَّط (غير منفَّذ بعد)** — تصميم مقترح، وقد يتغيّر قبل التنفيذ.

للشاشات السريعة (ST7789 وILI9341) وبطاقات SD وذاكرات الفلاش وبعض الحساسات. النقل بالعتاد وDMA، فالتوقيت دقيق.

## `spi.begin(sck, mosi, miso [, opts])`
يهيئ الناقل. `opts`: `freq` (افتراضي 1000000)، `mode` (0..3، الافتراضي 0).

## `spi.device(cs, [freq [, mode]]) → dev`
يعرّف جهازًا على رجل اختيار الشريحة `cs`.

## `dev:transfer(bytes [, n_rx]) → bytes`
يرسل ويستقبل في الوقت نفسه (يعيد بايتات المستقبَل).

## `dev:write(bytes)`
يرسل فقط. النقل الكبير (أكثر من 64 بايت) يتم بـ DMA.

```lua
--@pins 4,5,6,7
spi.begin(4, 5, 6)
local flash = spi.device(7, 4000000)
local id = flash:transfer({ 0x9F }, 3)
log(string.format("%02X %02X %02X", id[1], id[2], id[3]))
```

## الشاشات
رسم الشاشات الكبيرة بـ Lua بكسلًا بكسلًا بطيء. مخطط وحدة `gfx` في الفيرموير (مخزن إطار ورسم نص ومستطيلات)، يتحكم بها السكريبت وتُرسل بـ DMA.

## حدود
ناقل SPI واحد عام على C3، يشترك فيه السكريبتات بقفل. عدد الأجهزة محدود بعدد أرجل `cs` المتاحة.
