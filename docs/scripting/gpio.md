# gpio — الأرجل الرقمية

> **✅ منفَّذ بالكامل (v0.5):** `gpio.mode` (`"out"` `"in"` `"in_pullup"` `"in_pulldown"` ومرادفاتها `"pullup"` `"pulldown"`)، و`gpio.write` و`gpio.read` و`gpio.toggle` و`gpio.on_change(pin, fn [, debounce_ms])` و`gpio.off_change(pin)`.
> **ملاحظات:** المراقبة بفحص دوري كل ~10ms (تكفي للأزرار والمفاتيح)، أما النبضات الأقصر فتحتاج وحدة التقاط الحواف المخططة في [timing.md](timing.md). حتى 6 مراقبات لكل سكريبت. الرجل تُحجز تلقائيًا عند أول استعمال (لا `--@pins` بعد)، والمسموح 0–10 و20 و21.

يجب أن تكون الرجل معلنة في `--@pins` وإلا حدث خطأ.

## `gpio.mode(pin, mode)`

| mode | المعنى |
|---|---|
| `"in"` | دخل عائم |
| `"in_pullup"` | دخل مع مقاومة رفع داخلية |
| `"in_pulldown"` | دخل مع مقاومة خفض داخلية |
| `"out"` | خرج |

## `gpio.write(pin, value)`
يكتب `0` أو `1` على رجل خرج (يقبل أيضًا `true`/`false`).

## `gpio.read(pin) → 0 | 1`
يقرأ الحالة الحالية، ويعمل على رجل خرج أيضًا (يعيد آخر قيمة مكتوبة).

## `gpio.toggle(pin)`
يعكس حالة رجل خرج.

## `gpio.on_change(pin, fn [, debounce_ms])`
يستدعي `fn(value)` عند كل تغيّر في الدخل. `debounce_ms` افتراضيًا 20 لتجنّب ارتداد الأزرار.

```lua
gpio.mode(4, "in_pullup")
gpio.on_change(4, function(v)
  if v == 0 then log("الزر مضغوط") end
end)
```

## `gpio.off_change(pin)`
يلغي المراقبة.

## ملاحظات
- أرجل `18` و`19` (USB) محظورة.
- أرجل الإقلاع `2` و`8` و`9`: مسموحة لكن مع **تحذير**، فالتوصيل الخاطئ عليها يمنع الإقلاع.
- على كثير من لوحات ESP32-C3 SuperMini الليد المدمج على `8` وزر BOOT على `9`، وللتأكد راجع مخطط لوحتك.
