# system — `log` و`storage` و`bus` و`sys`

> **✅ منفَّذ بالكامل (v0.6):** `print`/`log` و`sys.millis` `sys.uptime` `sys.heap` `sys.temp` `sys.version` و`storage.get/set/remove/clear` و`bus.publish/subscribe/unsubscribe`. التفاصيل الفعلية في القسم **«المطبّق فعليًا»** في آخر الملف.

## log
`log(...)` يكتب في **الطرفية** (تبويب 💻) مسبوقًا باسم السكريبت. يقبل عدة معاملات، و`print` مرادف له. السطر حتى 160 حرفًا.

## storage — حفظ قيم بين التشغيلات
- `storage.get(key [, default])`
- `storage.set(key, value)` (رقم أو نص أو منطقي)
- `storage.remove(key)`

لكل سكريبت مخزن خاص، حتى **2KB**، ويُحفظ في `/scripts/.data/`. الكتابة تُدمج ولا تتجاوز مرة كل بضع ثوانٍ لحماية الفلاش.

```lua
local count = storage.get("boots", 0) + 1
storage.set("boots", count)
```

## bus — التبادل بين السكريبتات
- `bus.publish(topic, value)`: يرسل لكل المشتركين (رقم أو نص أو منطقي أو جدول بسيط).
- `bus.subscribe(topic, fn)`: يستدعي `fn(value)` عند كل نشر.

```lua
-- سكريبت أ
bus.publish("temp", 29.5)
-- سكريبت ب
bus.subscribe("temp", function(v) log("وصلت الحرارة", v) end)
```

## sys
- `sys.millis()`: ميلي ثانية منذ إقلاع الجهاز.
- `sys.heap()`: الذاكرة الحرة بالبايت.
- `sys.deep_sleep(seconds, {pins}, level)`: نوم عميق بعد نحو 0.8 ثانية (تتوقف السكريبتات والواي فاي وتُفقد ذاكرة RAM، ثم يُقلع الجهاز من جديد عند الاستيقاظ). `seconds` مؤقت الاستيقاظ (حتى 30 يومًا، 0 = بلا مؤقت). `pins` أرجل الاستيقاظ من **0 إلى 5 فقط** (أرجل RTC)، و`level` = 1 (افتراضي: استيقاظ عند جهد عالٍ، مع سحب للأسفل داخلي) أو 0 (منخفض، مع سحب للأعلى). لا بد من مؤقت أو رجل واحدة على الأقل، وإلا خطأ. زر RESET يوقظ الجهاز دائمًا.
  ```lua
  sys.deep_sleep(300)            -- نم 5 دقائق
  sys.deep_sleep(0, {3}, 0)      -- استيقظ حين تُوصَل GPIO3 بالأرض
  ```
- `sys.wake_reason()`: سبب آخر إقلاع: `"timer"` أو `"gpio"` (مع رقم الرجل كقيمة ثانية) أو `"reset"`. تظهر أيضًا في بطاقة الحالة.
- `sys.temp()`: حرارة المعالج الداخلية بالدرجة المئوية (رقم عشري، تقريبية ±عدة درجات).
- `sys.version()`: إصدار الفيرموير.

## ✅ المطبّق فعليًا (v0.6): storage و bus

### storage
```lua
storage.get(key [, default])   -- قيمة محفوظة أو default (أو nil)
storage.set(key, value)        -- رقم أو نص (حتى 200 حرف) أو منطقي؛ nil يحذف المفتاح
storage.remove(key)
storage.clear()                -- يمسح مخزن هذا السكريبت
```
- مخزن **خاص بكل سكريبت** باسمه، يُحفظ في `/scripts/.data/<name>.json` ويبقى بعد إعادة التشغيل وإعادة تشغيل السكريبت نفسه.
- الحد **2KB** للمخزن (خطأ `storage full` عند التجاوز). المفاتيح: حروف وأرقام و`_` و`-` حتى 15 حرفًا.
- **الكتابة على الفلاش تُدمج:** تُحفظ بعد 3 ثوانٍ من أول تعديل، وفورًا عند إيقاف السكريبت. فانقطاع الكهرباء خلال هذه الثواني الثلاث يضيّع آخر تعديل.
- الأعداد الصحيحة تبقى صحيحة، والعشرية 32 بت (`30.0` تعود `30`).
- حذف السكريبت 🗑 من المختبر يحذف مخزنه أيضًا. من الطرفية: `data <name>` يعرض ما هو محفوظ.

### bus
```lua
bus.publish(topic, value)        -- لكل المشتركين الآخرين
bus.subscribe(topic, function(value) ... end)   -- مشترك واحد لكل topic في السكريبت
bus.unsubscribe(topic)
```
- القيمة: رقم أو نص أو منطقي، أو **جدول بسيط** (مصفوفة، أو كائن بحقول نصية وقيم بسيطة، حتى 12 عنصرًا). الحد 119 بايت بعد التحويل إلى JSON. الجداول المتداخلة والدوال غير مسموحة.
- التوزيع **غير متزامن**: `publish` يعود فورًا، والمشترك يستقبل في دورته. **لا يصل المنشور إلى السكريبت نفسه.**
- الطابور 16 رسالة؛ عند الامتلاء تُسقط الجديدة ويُسجَّل ذلك في الطرفية. حتى 8 اشتراكات لكل سكريبت.
- للاختبار من الطرفية: `pub temp 29.5` أو `pub status {"ok":true,"n":3}` (يصل لكل المشتركين).
