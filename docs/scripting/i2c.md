# i2c — ناقل I2C

> **✅ منفَّذ (v0.7)** — انظر قسم **«المطبّق فعليًا»** في آخر الملف فهو المرجع (الشرح أدناه هو التصميم الأصلي وفيه فروق: لا `--@pins`، ونتائج الأخطاء `nil, "سبب"`).

الناقل **مشترك** بين السكريبتات، والجهاز ينظّم الوصول بقفل فلا تتداخل الرسائل. البيانات تُمرَّر كجداول أرقام (بايتات 0..255).

## `i2c.begin(sda, scl [, freq])`
يهيئ الناقل. `freq` افتراضيًا `100000` (يمكن `400000`). إن كان مهيأً بنفس الأرجل لا يحدث شيء، وبأرجل مختلفة يحدث خطأ.

## `i2c.scan() → {addr, ...}`
يعيد جدول عناوين الأجهزة الموجودة.

## `i2c.write(addr, bytes) → ok`
`bytes` جدول أرقام أو نص. يعيد `true` عند نجاح الإرسال.

## `i2c.read(addr, n) → {bytes} | nil`
يقرأ `n` بايت.

## `i2c.write_read(addr, tx, n) → {bytes} | nil`
يرسل ثم يقرأ في معاملة واحدة (أغلب الحساسات).

## `i2c.write_reg(addr, reg, value)` و`i2c.read_reg(addr, reg [, n]) → value | {bytes}`
اختصارات لأجهزة تعتمد على سجلات.

```lua
--@pins 6,7
--@needs i2c
i2c.begin(6, 7, 400000)
for _, a in ipairs(i2c.scan()) do log(string.format("وُجد جهاز: 0x%02X", a)) end
```

## أخطاء شائعة
- عدم وجود مقاومات رفع (4.7k) على SDA وSCL (بعض اللوحات تضعها).
- عنوان خاطئ: SSD1306 عادة `0x3C`، وBME280 `0x76` أو `0x77`.

## ✅ المطبّق فعليًا (v0.7)

```lua
i2c.begin(sda, scl [, freq])        -- freq: 10000..1000000 (الافتراضي 100000)
i2c.stop()                          -- يتخلى هذا السكريبت عن الناقل
i2c.scan()                          --> {0x3C, 0x76, ...}   (العناوين 0x08..0x77)
i2c.write(addr, bytes)              --> true | false, err
i2c.read(addr, n)                   --> {bytes} | nil, err
i2c.write_read(addr, tx, n)         --> {bytes} | nil, err   (إعادة بدء بلا إيقاف)
i2c.write_reg(addr, reg, value)     --> true | false, err    (value رقم 0..255 أو جدول/نص بايتات)
i2c.read_reg(addr, reg [, n])       --> number | {bytes} | nil, err   (بلا n: رقم واحد)
```

- `bytes` جدول أرقام صحيحة 0..255 أو نص. الحد **128 بايت** للمعاملة الواحدة، والعنوان 1..126.
- **الناقل مشترك:** أول سكريبت يستدعي `i2c.begin` يهيّئه وتصير الرجلان للناقل (لا يستعملهما `gpio`). أي سكريبت آخر يستدعي `i2c.begin` بنفس الرجلين يشارك الناقل، وبرجلين مختلفتين يحدث خطأ. حين يتوقف آخر مستعمل يُغلق الناقل وتتحرر الرجلان.
- **رموز الأخطاء** (القيمة الثانية المعادة): `nack_addr` (لا جهاز بهذا العنوان) و`nack_data` و`timeout` و`short_read` و`error`.
- الزمن الذي يقضيه الناقل في الانتظار لا يُحسب من مهلة الـ200ms للاستدعاء، لكن لا تُكثر من العمليات في استدعاء واحد.
- الأرجل المسموحة: 0–10 و20 و21 (الرجلان 8 و9 للإقلاع، فتجنّبهما للناقل إن أمكن). المقاومات الخارجية 4.7k رفعًا على SDA وSCL مطلوبة إن لم تكن على اللوحة.
- تُوصل شاشة SSD1306 عادة على `0x3C`، وBME280 على `0x76` أو `0x77`.

```lua
i2c.begin(6, 7)
local id = i2c.read_reg(0x76, 0xD0)     -- رقم واحد
local raw = i2c.read_reg(0x76, 0xF7, 8) -- جدول من 8 بايت
local ok, err = i2c.write(0x3C, { 0x00, 0xAE })
if not ok then print("write failed:", err) end
```
